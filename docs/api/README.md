# API contract

The list of every request the apps send to the backend and what comes back. Owned by the backend team; the apps build against it.

**Status:** milestone 1 endpoints are in [`openapi.yaml`](openapi.yaml) (OpenAPI 3). Open it in https://editor.swagger.io
or the VS Code "OpenAPI (Swagger) Editor" extension to browse it. Runnable examples: [`backend/requests.http`](../../backend/requests.http).
Announce every change in the team chat before merging it.
